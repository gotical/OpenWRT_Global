# OpenWRT Global

**OpenWRT Global** — Android-приложение для удобного управления роутерами **OpenWrt**
по SSH. Работает с любой прошивкой OpenWrt (и совместимыми), как со стандартным
`dropbear`, так и с `openssh`.

> Версия **4.1.0** — большой выпуск: полноценный файловый менеджер, новый замер
> скорости, синхронизация времени, быстрый выбор DNS и десятки исправлений.

---

## Возможности

### Wi-Fi и сеть
- **Управление Wi-Fi**: настройка точек доступа, гостевой сети, расписания, смена
  канала и ширины канала, перезагрузка Wi-Fi.
- **Анализатор каналов**: живая карта занятости каналов (роутер + телефон),
  ширина 20/40/80/160 МГц, рекомендации по свободному каналу, установка канала.
- **WPS-аудит**: проверка безопасности беспроводной сети (WPS / Pixie Dust),
  отключение WPS, включение блокировки после неудачных попыток.
- **Сканер сети (nmap)** и список подключённых клиентов с детализацией.
- **Wake-on-LAN** — удалённое включение устройств в сети.
- **Смена MAC** (MAC Changer) — случайный или заданный MAC для интерфейса.

### Безопасность и блокировки
- **Фаервол**: зоны, правила, проброс портов, переадресация.
- **Блокировка рекламы/трекеров** через dnsmasq/AdGuard.
- **AdGuard Home**: вкл/выкл защиты, статистика запросов и блокировок.
- **Быстрый выбор DNS**: Yandex (обычный/Безопасный/Семейный), Cloudflare, Google,
  AdGuard, Quad9, DNS.SB, SkyDNS (РФ), OpenDNS — применяется в один тап.

### Файловый менеджер (USB / SSD / HDD)
- Полноценный обзор папок на накопителе.
- **Скачивание** файлов на телефон (SFTP + резервный метод).
- **Загрузка** файлов с телефона (выбор через системный пикер).
- Переименование, создание папок, удаление, информация о файле.
- **Форматирование** накопителя (mkfs) с выбором файловой системы
  (ext4, exFAT, FAT32 и др.).
- Автоопределение флешек/SSD/HDD (в т.ч. без `lsblk` — через `/proc`).

### Пакеты и система
- **Управление пакетами** (opkg): установка, удаление, обновление, список
  обновлений.
- Обновление прошивки, перезагрузка роутера.
- **Синхронизация времени роутера с телефоном** (порог 60 с, UTC).
- **Терминал** с историей, избранными командами, клавишами Esc/стрелки.
- **Бэкап и восстановление** конфигурации (шифрование AES-256, случайный IV).
- **VPN**: WireGuard / AmneziaWG, OpenVPN, IPsec, PPTP, L2TP, SSTP.
- **Зависимости пакетов** и напоминания.

### Измерения и инструменты
- **Замер скорости интернета**: задержка и джиттер, скачивание с живым
  прогрессом, загрузка, живой диалог.
- **AI-ассистент** — вопросы по настройке роутера через DeepSeek / OpenRouter /
  OpenAI.
- **Раздел «О приложении»** и исходный код.

## Требования

- Android **7.0 (API 24)** и выше.
- Роутер с **OpenWrt** (SSH-доступ: IP, порт, логин/пароль или ключ PEM).
- Права root в терминале для функций, требующих монтирования/форматирования.

---

## Интерфейс

- **Выбор языка**: русский, украинский, казахский, белорусский.
  Выбранный язык сохраняется между запусками приложения. Переведены все экраны,
  основные диалоги, кнопки, уведомления и статусы.
- Тёмная/светлая тема.
- Уведомления о новых подключениях (опционально).
- Защита экрана (biometric / PIN) — опционально.

## Сборка из исходников

```bash
flutter pub get
flutter build apk --target-platform android-arm64
```

> Примечание: для сборки релиза используется подпись ключом загрузчика
> (Rustore / Google Play). APK собирается с `debuggable=false` и подписывается
> вашим ключом перед установкой (`apksigner sign`).

Сборка также выполняется в Termux на Android (системный Dart, glibc-инструменты
через `glibc-runner`, `aapt2` из build-tools; релизная AOT-сборка на arm64-хосте
недоступна — используется JIT `--debug` `kernel_blob`).
