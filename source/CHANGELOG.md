# Изменения в v4.0.8

## Исправленные ошибки

### SSH / работа с роутером (`openwrt_service.dart`)
- **Гостевая сеть не создавалась**: переменные в команде были экранированы от
  Dart-интерполяции (`\${radioDevice}` → пустое значение в shell). Исправлено;
  заодно убран ошибочный `uci add_list network.lan.ipaddr='10.0.0.1/24'`,
  который ломал настройку LAN.
- **Включение/выключение гостевой сети и расписания Wi-Fi не работало**:
  та же проблема с `\$section`/`\${...}` — секция и значения не подставлялись.
  Расписание теперь также выставляет `sched_enabled=1` и делает `wifi reload`
  (раньше расписание молча не срабатывало).
- **Проброс портов создавался с пустыми полями** (`name`, `proto`, порты):
  `\${name}` → пусто. Исправлено + добавлено `enabled='1'`.
- **Восстановление бэкапа конфигурации (`restoreConfig`) передавало пустую
  строку** (`'\$base64Config'` → `$base64Config` — несуществующая переменная shell).
- **Wake-on-LAN не работал**: `wol '\$mac'` → пустой MAC. Исправлено, добавлен
  запасной вариант через `etherwake`.
- **Установка пакетов обрывалась по таймауту**: `opkg update && opkg install`
  выполнялись с таймаутом 30 с. Добавлен `runCommandLong` (5 мин) для установки/
  удаления/обновления списков пакетов, обновления прошивки (auc) и установки
  зависимостей.
- **`fetchTopology` мог упасть с RangeError**: для коротких строк ARP-таблицы
  читался `parts[5]`. Добавлена проверка длины.
- **WPS-аудит не находил пароль из UCI**: поле `ssid` никогда не заполнялось.
  Теперь SSID извлекается из скана.
- **Краш при определении производителя**: `fetchMacVendor` вызывал
  `substring(0, 6)` на коротких/битых MAC. Добавлена защита.
- **Сам роутер показывался в списке клиентов** на подсетях ≠ 192.168.1.1:
  IP роутера теперь определяется динамически через ubus/uci.
- **DNS-серверы без экранирования**: значения экранируются, пустые пропускаются.
- **Имена VPN-интерфейсов санируются** (только `[a-zA-Z0-9_]`): раньше имя
  с пробелом/кавычкой ломало команды uci.

### Экраны
- **«Отключить Wi-Fi WAN» удалял последнюю wifi-iface секцию** — могла
  отключиться основная точка доступа. Теперь удаляется только секция `mode='sta'`.
- **MAC Changer**: поле произвольного MAC сбрасывалось при каждом обновлении
  экрана, а кнопка «Применить» игнорировала введённый текст (применяла новый
  случайный MAC). Теперь применяется введённый MAC (с проверкой формата);
  случайный MAC генерируется криптостойко.
- **Бэкап конфигурации не содержал паролей/ключей** (`toJson` их не включает) —
  восстановить бэкап было невозможно. Теперь экспортируются все поля
  (зашифрованы AES-256).
- **Статический IP в мастере WAN**: цифровая клавиатура не показывала точки —
  ввод IP был неудобным. Исправлено.

### Прочее
- **AI-ассистент отправлял ключи DeepSeek/OpenRouter на OpenAI**: запрос всегда
  шёл в `api.openai.com` с ключом выбранного провайдера (и падал с 401).
  Теперь запросы идут в API выбранного провайдера (DeepSeek / OpenRouter / OpenAI).
- **Бэкап (AES-256)**: IV генерировался детерминированно (FortunaRandom с нулевым
  сидом) — одинаковые данные шифровались одинаково. Теперь случайный IV через
  `Random.secure()`, добавлена проверка PKCS#7-паддинга при расшифровке.
- **Проверка «Режим отладки» всегда показывала false**: метод `isDebug` не был
  реализован в MainActivity. Добавлен.
- **Глобальный перехват ошибок**: необработанные исключения теперь логируются
  через AppLogger (раньше терялись).
- **Список «известных клиентов» рос бесконечно** — ограничен 500 записями.
- **Версия приложения поднята до 4.0.8** (versionCode 408).

# Новое в v4.0.8 (по мотивам изучения open-source аналогов)

Изучены и частично перенесены идеи из:
- **luci-mobile** (github.com/cogwheel0/luci-mobile) — Flutter-клиент OpenWrt
- **OpenWrtManager** (github.com/hagaygo/OpenWrtManager) — Flutter-менеджер OpenWrt
- **openwrt-router-control** (github.com/Vihtoor/openwrt-router-control) — SSH-терминал и Wi-Fi анализатор
- **Stryker** (github.com/zalexdev/strykerapp) — диагностика сети

## Функциональные улучшения
- **Запасной адрес роутера**: в форме добавления/редактирования роутера появилось
  поле «Запасной адрес (опц.)» (DDNS/внешний IP). Если основной адрес недоступен,
  приложение автоматически пробует запасной (идея из luci-mobile).
- **Проверка подключения до сохранения**: кнопка «Проверить» в форме роутера —
  сразу видно, работает ли адрес/логин/пароль (OpenWrtManager).
- **«Отключить» Wi-Fi клиента**: новый чип в карточке клиента — мгновенно
  выгоняет устройство из сети (hostapd del_client / disassociate) (OpenWrtManager).
- **Определение ОС клиента по TTL**: в карточке клиента показывается
  «Linux/Unix · ~2 хопа» по одному ping, без nmap (Stryker).
- **Живая скорость WAN на дашборде**: карточки «↓ Скорость / ↑ Скорость»
  (разность счётчиков между опросами) (OpenWrtManager / luci-mobile).
- **Терминал**: постоянная история команд (переживает перезапуск), избранные
  команды, кнопки ESC и стрелок ◀▲▼▶, диалог истории с удалением
  (openwrt-router-control).

## UX и надёжность
- **Выбор темы** (Системная / Светлая / Тёмная) — в настройках (шторка) и на
  экране «О приложении» (luci-mobile / OpenWrtManager).
- **Автообновление дашборда только при активном приложении и видимой вкладке** —
  меньше трафика и расхода батареи (OpenWrtManager).
- **Человекочитаемые ошибки**: вместо сырого `Exception` — объяснение
  («Таймаут подключения…», «Ошибка авторизации…») + кнопка «Диагностика» для
  копирования (OpenWrtManager).

# Версия 4.0.9 — файловый менеджер, новый speedtest, UI

## Файловый менеджер (USB / SSD / HDD)
- Полноценный менеджер накопителей: навигация по папкам (хлебные крошки),
  индикатор занятости диска (df).
- **Скачивание** файла с накопителя на телефон (SFTP, а на dropbear — через
  base64-чанки) с живым прогрессом и скоростью.
- **Загрузка** файла с телефона на накопитель (SFTP) — выбор через системный
  файловый пикер.
- Переименование, удаление, создание папок, информация о файле/папке.
- **Форматирование** раздела: FAT32, ext4, exFAT, NTFS, BTRFS, XFS
  (разрушающая операция с подтверждением).
- Иконки файлов по типу (видео, фото, музыка, архивы, PDF, текст, APK/ISO).

## Speedtest — полностью переработан
- **Задержка и джиттер** (ping 1.1.1.1).
- **Скачивание с живым прогрессом** — фоновая закачка + опрос размера файла,
  показывается текущая скорость в Мбит/с.
- **Загрузка** (curl на Cloudflare __up).
- Фолбэк на несколько серверов (Cloudflare / OVH / Tele2) и wget.
- Живой диалог с большой цифрой скорости.

## UI / прочее
- Скелетоны-загрузка на дашборде, в клиентах, в пакетах.
- Выбор темы (Системная/Светлая/Тёмная) в настройках и «О приложении».
- Переводы новых функций на украинский, казахский, белорусский.
- Сборка: **полноценный AOT release** (быстрый старт, ~27 МБ), подписан
  ключом rustore, debuggable=false.

# Версия 4.0.10 — синхронизация времени с телефона

## Новая функция
- **Авто-синхронизация времени роутера с телефоном**: при входе в приложение
  проверяется время роутера (`date`) и время телефона; если расхождение больше
  60 секунд — на роутер ставится время телефона (в UTC, через `date -u -s`).
- Переключатель **«Синхронизация времени с телефона»** в настройках
  (шторка → Настройки), по умолчанию включён.

## Исправлено / улучшено
- Шейдер InkSparkle теперь компилируется корректно (impellerc через glibc-runner) —
  убран «Unhandled platform error» при каждом запуске.
- Сборка: JIT arm64, подпись rustore, debuggable=false.

## Сборка на Termux (заметки)
- Flutter SDK поднят на Termux: системный Dart, glibc-инструменты (gen_snapshot,
  impellerc, font-subset, aapt2) запускаются через glibc-runner.
- AOT release на arm64-хосте невозможен (нет android-gen_snapshot под linux-arm64),
  поэтому используется JIT-сборка (kernel_blob) — работает на dropbear и openssh.

# Версия 4.0.12 — быстрый выбор DNS + исправление USB-накопителей

## Новое
- **Быстрый выбор DNS за один тап** в Настройки → DNS: пресеты из подборки
  comss.ru (Yandex DNS обычный/Безопасный/Семейный, Cloudflare, Google, AdGuard,
  Quad9, DNS.SB, SkyDNS РФ, Волга DNS). При применении старые DNS очищаются,
  затем добавляются выбранные (через uci + dnsmasq + resolve).
- Добавлены **быстрые DNS для РФ/СНГ**: SkyDNS, Волга DNS, DNS.SB — низкий
  пинг в регионе.

## Исправлено
- **USB-флешка определялась как «модем», а тап по ней ничего не делал**:
  теперь накопители ищутся и через `lsblk`, и резервно через `/proc/partitions`,
  `/proc/mounts` и `/sys/class/block` (там, где на роутере нет lsblk). Строка
  накопителя в списке всегда кликабельна: смонтирован → открыть файловый
  менеджер, не смонтирован → подключить и открыть.
- Ключевые слова модема ужесточены, чтобы накопитель не попадал в «USB-модем».
